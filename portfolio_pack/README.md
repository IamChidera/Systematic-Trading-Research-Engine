# Portfolio Pack

This folder contains recruiter-facing and application-ready material for the Systematic Trading Research Engine project.

Use it when updating:

- CV project sections
- LinkedIn Featured and posts
- GitHub pinned repository descriptions
- recruiter messages
- interview preparation notes
- portfolio walkthroughs

Best files to show:

Recommended use order:

1. Pin the repo on GitHub.
2. Add the one-line summary to LinkedIn Featured.
3. Put the 3-line CV version on your CV.
4. Use the recruiter DM when messaging hiring managers.
5. Prepare the interview talking points before calls.

This project should be described as a research and engineering platform, not as financial advice or guaranteed trading performance.
